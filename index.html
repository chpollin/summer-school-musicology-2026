Sessions 3 and 4 · Thursday 17 September · 15:00–16:30 and 17:00–18:30

Large Language Models for Research Data Workflows: Hands-On Practice

Use LLMs for coding and build small research tools through Promptotyping. Maintain project knowledge, select useful context and guide tool-supported agent work with checks and feedback.

Session 3 · Guided hands-on · 15:00–16:30

Work through a cumulative exercise with the supplied research materials. Inspect the inputs, document the requirements, use an agent to implement a first working tool and check the result together.

Session 4 · Independent work · 17:00–18:30

Continue from the guided exercise. Choose a research requirement, provide the relevant project context, implement it with the agent and inspect the result against the sources.
