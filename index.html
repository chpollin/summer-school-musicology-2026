From running a workflow to building a research tool

We return to PDF-to-PNG conversion to compare how you and an agent execute the same task. The TEI corpus from Session 2 becomes input for the tool-building exercise in step 3.

  1. Run the workflow yourself. Open the first package in Visual Studio Code, follow its guide and run the supplied script. Inspect the generated images against the PDFs.
    Hands-on 1 · Python in Visual Studio Code · ZIP
  2. Repeat the workflow with an agent. Give the agent the same task, script and PDFs. Observe its tool use, inspect the outputs and compare them with your first run.
    Hands-on 2 · AI Harness · ZIP
  3. Use LLMs for coding through Promptotyping. State a research requirement and record the relevant data, constraints and checks. Reuse your TEI files and images from Session 2 to implement and inspect a first tool together. A source viewer is the worked example.
    TEI corpus layout & reference bundle
  4. Continue independently in Session 4. Choose a requirement for your own research tool or extend the guided example. Supply the relevant context, inspect the agent’s changes and verify the result against the data. Record what works and what remains uncertain.

Both hands-on ZIPs contain their guide, the supplied Python script and all seven input PDFs. Keep your Session 2 tei/ and png/ folders together so the image links remain usable.

Practices used throughout

Knowledge Engineering
Maintain project knowledge about the research purpose, data, requirements, decisions and checks.
Context Engineering
Select the instructions, source material and project knowledge needed for the current task.
Agentic Engineering
Guide the agent’s tool use, inspect its actions and results, and provide feedback for the next change.
