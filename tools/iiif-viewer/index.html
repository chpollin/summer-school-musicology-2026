Your digital object

Try the transformation yourself

Change the title or swap two page references in your XML. Save the file, select it again and open it in Mirador. Compare the metadata and page order.

Use Python in the terminal

Download the exercise package, extract it and open the folder in your editor. With Python 3.11 or later installed, run:

python -m pip install "lxml>=5,<7" "Pillow>=10,<13"
python build_manifest.py metadata.xml

Return to this page and select the generated manifest.json and the images. You do not need to start a local server. On macOS/Linux, use python3 if required.

Which XML and manifests can I use?

This exercise supports the project-specific XML template and the simple IIIF Presentation 3 image manifests generated by the supplied Python script. It is not a general METS, TEI or IIIF import tool.

Each <page xlink:href="images/page-001.jpg"/> must refer to a selected image. Filenames must be unique, including across folders. The XML page order determines the viewer order. Missing files are reported.

The browser maps the selected images to temporary local addresses. Remote images and services in uploaded manifests are not fetched. Reloading the page clears the loaded object. Selecting files does not publish a shareable IIIF resource.
